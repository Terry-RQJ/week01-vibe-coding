### 发现 1：浏览记录时间格式太机器（A6）
- 现象：时间胶囊直接显示 `2026-09-28`（ISO 日期），用户看不出"多久之前看的"
- 根因：`store.js` 的 `addHistory` 只存 `today()`（YYYY-MM-DD，无时分秒），`ui.js` 直接原样渲染
- 修复：
  - `js/ui.js` 新增 `formatRelativeTime()`：兼容完整 ISO 与纯日期旧值，输出「刚刚 / X 分钟前 / 今天 HH:MM / 昨天 HH:MM / X 天前 / YYYY-MM-DD」；`renderCardList` 的 history 模式改用它，`title` 属性保留完整原始时间（悬停可看）
  - `js/store.js` 的 `addHistory` 改存 `new Date().toISOString()`（带时分秒），旧 localStorage 数据无需迁移
- 验证：截图 `day14-history-times.png`（电脑）、`day14-history-mobile.png`（375 宽）——「刚刚 / 15 分钟前 / 今天 11:44」三级全部正确

### 发现 2：手机真机打不开（连接不上服务器）
- 现象：手机浏览器访问 `http://localhost:8000` 连接失败
- 根因：`localhost` 在手机上指向手机自己，不是电脑；且原服务器只绑 `127.0.0.1`，就算改 IP 也连不上；Windows 防火墙默认拦入站
- 修复（环境，不改代码）：服务器改绑 `0.0.0.0` + 防火墙放行 8000 端口入站（规则名 "Python HTTP Server 8000"）
- 手机访问地址：`http://172.18.61.176:8000/`（电脑与手机需在同一 WiFi）
- 验证：`curl http://172.18.61.176:8000/index.html` 返回 200
