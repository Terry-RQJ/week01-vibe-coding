关于本站

这是一个什么样的站

一个公益性质的法律常识站。目标只有一句话：让一个普通人在「撞上事」的瞬间，能 3 分钟搞懂「这事归哪条法律管、我现在该怎么做」。

站内现有 120+ 张情境卡片、260+ 条法条引用，覆盖劳动、消费、借贷、婚姻家庭、交通、邻里·名誉六大类日常场景。 每张卡片只讲清四件事：这是什么情形、对应哪条法律、我现在该怎么做、还能延伸了解什么——不讲空话，不堆术语。

全站不要注册、不要登录、不收集任何个人信息。你的收藏和浏览记录只存在你自己设备的浏览器里，我们既看不到、也传不走。

内容是怎么做出来的

每张卡片都要走完这四步才会发布，不做「随手一发」：

  1. 选题——从六大类高频生活场景里，按真实搜索词与常见纠纷类型排序，不凭感觉挑。
  2. 起草——依据法条原文与典型案例拟初稿，每张卡片的结论都要能落回具体条文。
  3. 复核——逐条核对法条编号与原文用词，并检查行动步骤是否超出「通用指引」的边界、会不会变成给个案下结论。
  4. 发布并标注——每张卡片带「最后核验日期」，法条带官方出处链接，日期过期会重新核对。

坦白讲：本站由个人以学习项目的形式维护，AI 参与起草、人工负责核对。它不是律所，也不假装自己是。发现错误请一定告诉我们，见下方「反馈」。

法条出处：你可以自己核验

本站所有法条都附官方出处链接，点开即可核对原文。我们优先使用下列官方来源：

  • 中国人大网——法律全文与立法说明
  • 中国政府网——行政法规与国务院文件
  • 最高人民法院——司法解释与指导案例
  • 国家法律法规数据库——检索入口（部分条文详情页跳转不稳定，故本站不以它作为唯一出处）

也可以直接去法条速查页，按法律名或条文关键词找到完整条文与「被哪些情形引用」。

发现错误？请告诉我们

法律内容最怕「差不多对」。如果你发现法条条号错了、原文有出入、步骤不适用，欢迎反馈——我们会核对后修正，并在页面上更新核验日期。

反馈入口： GitHub Issues （可直接留言，写明卡片标题与问题即可）；也可以直接在仓库提 Pull Request。

另外说明两件本站做不到的事：① 不代你处理任何具体纠纷；② 不回答「我这个案子能赢吗」这类个案判断。这两件事请交给 12348 或执业律师。
